Custom Shaders
===================

.. versionadded:: 0.49.0
   Support for custom shaders


Custom shaders in kitty are event driven and allow for all manner of visual
effects from the fun and blingy to useful visual aides. Users can write their
own custom shaders or use them from the large set that ship with kitty.
Browse the gallery below to watch some custom shaders that ship with kitty in
action.
