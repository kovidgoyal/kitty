Quickstart
===========

.. toctree::
   :hidden:

   binary
   build

Pre-built binaries of |datty| are available for both macOS and Linux. See the
:doc:`binary install instructions </binary>`. You can also :doc:`build from
source </build>`.

Additionally, you can use your favorite package manager to install the |datty|
package, but note that some Linux distribution packages are woefully outdated.
|datty| is available in a vast number of package repositories for macOS
and Linux.

.. image:: https://repology.org/badge/tiny-repos/datty-terminal.svg
   :target: https://repology.org/project/datty-terminal/versions
   :alt: Number of repositories datty is available in

See :doc:`Configuring datty <conf>` for help on configuring |datty| and
:doc:`Invocation <invocation>` for the command line arguments |datty| supports.

For a tour of datty's design and features, see the :doc:`overview`.
